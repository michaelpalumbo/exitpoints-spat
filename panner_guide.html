Quad Panner: Operator Guide

Created by Michael Palumbo, Nov 2026, for Exit Points #78

You move the instruments around the four speakers and set their levels. FOH handles gain, EQ and the backup PA. Everything is played from the nanoKONTROL2, the number keys and the room view.

Words used in this guide

WordMeans
UnitOne instrument (or one player's mics) that moves as a single sound. Up to 8 per set, one per nanoKONTROL2 strip.
SceneOne set's units, with their levels and settings: ensemble 1, ensemble 2, or switchemups 1-4.
ModeA way of moving, picked with the number keys (drift, orbit, hop...).
Movable / frozenA movable unit follows the mode. A frozen unit stays where it is. Switched with M.
HomeA unit's resting place in the room, set in mode 1. Shown as an X in the unit's colour. R sends a unit there.
PickupA knob or fader does nothing until you move it past its current value, so nothing jumps.
IN numberThe console channel(s) a unit uses, shown in its box (IN:5/6). Use it when talking to FOH.
Glide / cutWhether changes happen smoothly or instantly. TAB switches.
Line-upThe units chosen for a switchemups set.
SpreadHow big a unit sounds: from a point in one speaker to a wide, blurry sound shared by several. Shown as the halo around the unit.
RangeHow far a unit travels from its home in a mode. 0% stays home.

Before the show and each set

Before the show

  1. The monitoring switch is on Array Routing (see Monitoring switch).
  2. The test signals are off.
  3. Press reset show: every unit frozen, speed x1 and accel instant everywhere. Levels, spread, width, range, homes, loops and line-ups are kept.

Before each set

  1. Load the scene with the scene buttons (ensemble 1, ensemble 2, or switchemups 1-4).
  2. Check the unit boxes: each shows its name and its input channels (IN:5/6).
  3. Pick a mode with the number keys, then press M on the units you want moving.

Scenes

Each set is a scene: ensemble 1, ensemble 2, and switchemups 1-4. Load one with the scene buttons. A scene keeps its own levels, spread, width, homes, loops, assignments and per-mode settings, and all of it comes back when you load the scene again.

When a scene loads, every unit is frozen (except in set home positions) and the knobs and faders need to pick up again. The current mode stays the same.

The ensemble scenes are fixed. Switchemups scenes are built on the night: see Switchemups line-ups.

The room view

From top to bottom: the room, the mode buttons, the header, and the unit boxes.

The room

  • The square is the room, with the stage at the top. The four grey boxes are the speakers (FL, FR, BL, BR).
  • The small + is the calibration position: the point the four speakers are aligned to (the middle of the audience).
  • Each unit is drawn in its colour. Stereo pairs and mic groups show one dot per mic, joined by a line. A filled dot is movable, a hollow one is frozen.
  • The halo around a unit shows its spread: a small ring is a point source, a big one is spread over several speakers.
  • The coloured X marks each unit's home. HIDE / SHOW HOME POSITIONS in the header turns them off and on.
  • While you turn a range knob, the unit shows a line from its home to where its movement would reach at 100%, for 2 seconds.
  • In loop mode, each loop is drawn: thick where the unit travels, thin where it jumps.

Mode buttons and header

  • The mode buttons show the 10 modes; the current one is orange. Clicking one is the same as its number key.
  • The header shows the scene, the mode, and a one-line description of what the mode does.
  • EDIT LINE-UP appears only in switchemups scenes.
  • On the right: the overall speed, and the GLIDE / CUT button (blue for glide, with its time; orange for cut).

Unit boxes

One box per unit, matching the nanoKONTROL2 strips.

RowShows
1The unit number and its state: movable or frozen (and loop if it has one; in assign mode, its assigned mode)
2The unit's name
3Its input channels, e.g. IN:17/18/19/20

A full border means movable; just the bar on the left means frozen. The boxes only show state: use M and R on the nanoKONTROL2 to change it. (While editing a switchemups line-up, clicking a box opens the list of sources.)

The nanoKONTROL2

Each of the 8 channel strips belongs to one unit: fader 1, knob 1 and the S, M, R buttons of strip 1 all act on unit 1, and so on. The transport buttons choose what the knobs do.

Faders: levels

The fader sets the unit's level: 0 dB at the top, off at the very bottom. Levels are the same in every mode and are kept per scene. Set them at soundcheck; during the show, use them to fix something that's too loud or too quiet.

Faders use pickup: see Knobs, faders and pickup.

M: movable / frozen

  • Press M to make the unit movable (lit) or frozen (dark) in the current mode.
  • A frozen unit stays exactly where it is, wherever the mode had taken it.
  • Each mode keeps its own M state for each unit.
  • In set home positions, every M is lit and pressing it does nothing.

R: home

M is...Pressing R
off (frozen)The unit travels home and stays there.
on (movable)The unit travels home, then goes straight back to what the mode is doing (in loop mode, back onto its loop).

R flashes while the unit is on its way and goes dark when it arrives. The trip takes the glide time (or is instant with cut, and then the unit waits 1 second at home before going back). In set home positions, R does nothing: every unit is already home.

S: select and delete

DoWhereResult
Tapassign modeSelect the unit (slow flash). Tap again to deselect.
Hold 2 sloop mode (or a unit assigned to loop)Delete the unit's loop. It flashes fast while you hold; let go early to keep the loop. Hold several S buttons to delete several. In other modes it does nothing, so a loop can't be deleted by accident.

In loop mode, units with a loop show DELETE on their S button. S is lit while a unit is playing its loop.

Range, speed and accel belong to the mode, so the screen boxes them with the mode's name (e.g. ORBIT SETTINGS). In set home positions they do nothing and are greyed out. In assign mode, each unit's knob sets the value for the mode it's assigned to.

The screen version

The patch shows a copy of the nanoKONTROL2 that mirrors the real one, lights included. You can click its buttons, drag its knobs up and down, and click or drag its faders, and the results are the same as on the hardware. Screen knobs and faders set values directly, without pickup; the hardware then picks up from the new value. Holding S for 2 seconds works with the mouse too.

Knobs, faders and pickup

The computer can't move the nanoKONTROL2's knobs or faders, so when you change page, mode or scene, a knob is probably sitting somewhere different from the value it now controls. To stop values jumping:

A knob or fader does nothing until you move it through the current value. From then on it follows your hand.
BlueYellow
Knobarc: the current valuetick: where the hardware knob is
Faderbar: the current levelline: where the hardware fader is

Move the control until the yellow meets the end of the blue, and it takes over.

Glide and cut

TAB (or the GLIDE / CUT button) chooses how units change course:

  • Glide (blue): units move smoothly to their new path over the glide time (CYCLE page, knob 2).
  • Cut (orange): units jump straight there.

It applies when you change mode, press M, press R, or assign a mode. It doesn't change the hard jumps in hop, pulse or loop jumps: those always cut.

Modes

Every mode moves the movable units; frozen units stay put. Each unit has a fixed place in the pattern (by its number), so freezing one never moves the others.

KnobIn every mode except set home positions
rangescales how far the movement reaches from home
speedspeeds the pattern up or slows it down
accelgives the unit weight: it lags behind and swings into place

1 Set home positions

Every unit sits at its home, and every unit is always movable (all M lit; M does nothing). Drag a unit in the room view to give it a new home: that's where R sends it in every other mode. Homes are kept per scene.

R, range, speed and accel do nothing here and are greyed out. Use this mode to arrange the stage image at soundcheck, or as a resting state between sections.

2 Drift

Units wander slowly over the whole room, each on its own path. With range down, they wander only near their homes.

3 Orbit

Units circle the middle of the room, evenly spaced, at three different distances from the centre. Neighbouring units go in opposite directions. One lap takes about 40 seconds at speed x1.

4 Hop

Units jump between speakers at random, every 2 to 6 seconds, never to the speaker they're already on. With accel below instant, each jump becomes a straight, smooth move from speaker to speaker instead.

5 Pulse

Units jump between speakers on a shared beat (every 1.5 seconds at speed x1), each to a different speaker. Units with the same speed stay in step. Accel has no effect: pulse always jumps.

6 Swarm

A shared centre wanders around the room, and the units buzz around it, so they travel as a group.

7 Sway

Units sway from their home toward the back of the room and back again, about every 12 seconds, staggered so they don't all move together.

8 Perimeter

Units spread evenly around the walls and slowly circle the room. One lap takes about 90 seconds at speed x1.

9 Loop

Each unit follows a path you draw. Drag a unit in the room view: its path is recorded while you drag, and it loops as soon as you let go. At the end of each pass it glides back to the start in 0.4 seconds. Units without a loop stay home.

DoResult
Dragrecord a loop (replaces any loop the unit had)
Hold shift during part of the dragthat part becomes a jump: the unit cuts straight across it, taking no time (drawn as a thin line)
Hold shift as you click, then let go of shiftthe loop starts where you let go of shift
Hold the unit's S (DELETE) for 2 sdelete the loop

Speed changes how fast the loop plays back. Range has no effect on loops: they always follow exactly what you drew. Loops are kept per scene, so they come back when you return to loop mode.

Recording a loop makes the unit movable. Try pressing M and R while loops play: R sends a looping unit home and it returns to its loop.

0 Assign

Each unit runs the mode it's assigned to, so some can orbit while others hop or loop. Units start assigned to set home positions.

  1. Press 0.
  2. Tap S on the units you want (they flash slowly).
  3. Press a number key: the selected units get that mode and stop flashing.

0 again clears the selection. With nothing selected, number keys switch modes as usual (leaving assign).

The knobs follow each unit's assigned mode: turning unit 1's range while it's assigned orbit changes its orbit range, and you'll find the same value in orbit mode. Dragging works for units assigned to set home positions or loop. The unit boxes show each unit's assigned mode.

Switchemups line-ups

The third part of the show has 4 sets with players from the audience. Each set is its own scene (switchemups 1-4), and you choose its units from the sign-up sheet in the second intermission.

Create or edit a set

  1. Load switchemups 1 with the scene buttons.
  2. Click the blue EDIT LINE-UP button (just above the unit boxes). It turns orange and says DONE.
  3. Click a unit box. A list opens.
  4. Click the instrument or input for that player. Each entry shows its channels (IN:15).
    • Grey entries share a channel with another unit (the list says which).
    • Someone on a channel that isn't a named instrument? Pick the IN # entry for that channel.
    • Pick (empty) to clear a slot.
    • Several players on one unit? shift-click each of their sources (they're marked with a +), then click DONE and type a short name (up to 8 characters). They become one group unit that moves together.
  5. Repeat for each player (up to 8), then click DONE.
  6. Load switchemups 2 and repeat, then 3 and 4.

Then for each set: load it, set the levels with the faders, and press 1 to drag each unit to roughly where that player stands. All of it is saved as you go.

Start a set over

Press that set's erase button. It empties the line-up and forgets its levels, homes and loops. Only switchemups sets can be erased.

A problem with an input? Tell FOH the IN number from the unit box.

Monitoring switch

Practice (Laptop) - Direct-in MonitoringPractising on the laptop: every unit at its level, without the panning. Good for levels.
Practice (Laptop) - Post-Pan MonitoringPractising on the laptop: the panning folded down to stereo. Left and right movement comes through, front and back doesn't.
Before the show, check it's on Array Routing. The practice settings send sound to the laptop, not to the speakers.

What's saved

Settings are written to files next to the patch as you work, and read back when it opens. You never need to save the patch.

Saved automaticallyStarts fresh every time
Levels, spread, width, homes, loops, assignments, range / speed / accel for each mode (all per scene); overall speed and glide time; the switchemups line-upsMovable / frozen (everything starts frozen), the current mode, glide or cut, the knob page, assign selections, show / hide home positions

The speaker measurements are only saved on purpose (see Technical notes).

Technical notes

For maintaining the patch.

Signal flow

  • adc~ 1-24 (+ test signals) → panner gen~ → outlets 1-4 → USB returns → FL FR BL BR
  • panner gen~ outlets 5-6 (quad) → headphone monitor (every point at its level, before panning)
  • Control: dbap_behave → dbap_control → buffer~ dbap_pts / dbap_spk → gen~; state goes back out as dict dbap_state to the engine and the view.

Panner gen~

  • Parameters: rolloff (dB per doubling of distance, default 6), block (samples between gain updates, default 32; 1 is sample-accurate), mongain (headphone monitor, default 0.5).
  • buffer~ dbap_pts 1 5: 24 points x (x, y, level, slew ms, blur m). buffer~ dbap_spk 1 4: speakers x (x, y, delay ms, gain); frame 7 holds the speaker count.
  • Coordinates in metres, origin at the centre of the speakers, +y toward the stage.

Controller

  • [ctlin] → [pack 0 0] → dbap_nk.js; nk_screen.js sends screen value cc to the same inlet.
  • dbap_nk.js outlet 2 → [unpack 0 0] → [ctlout "nanoKONTROL2 CTRL"] for the LEDs (LED mode external).
  • CCs: knobs 8-15, faders 0-7, S 32-39, M 48-55, R 64-71, transport 41-46.
